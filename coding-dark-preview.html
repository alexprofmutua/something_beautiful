CLI · Shell · Homebrew · Cross-platform

colorBash

Color exact file and folder names in ls, not just file types.

Shell · PowerShell · Ruby formula · Homebrew · Scoop · AGPL-3.0

colorBash wraps interactive ls so specific names can keep their own colors. Save rules with cb <name> <color>, randomize visible entries with cb random, and keep unsupported ls modes safely falling back to the system command.

Install locally

git clone https://github.com/alexprofmutua/colorBash.git
cd colorBash
./install.sh --configure-shell

Desktop app · Python · PySide6 · macOS

neatify

A safer, smarter way to organize messy folders.

Python · PySide6 · PyInstaller · DMG packaging · MIT

Neatify started as a Python cleanup script and grew into a desktop app with folder browsing, arrange previews, custom rules, filtered search, move history, undo, themes, and macOS packaging. The core idea is simple: preview changes before moving files, then keep a history you can reverse.

Download for macOS

github.com/alexprofmutua/neatify/releases
Download Neatify-macOS.dmg
Drag Neatify.app into Applications

CLI · Search · Shell · AI mode

go_search

Search Google, DuckDuckGo, or Perplexity from the terminal.

Shell · Python URL encoding · Chrome incognito · Perplexity API

go_search keeps lookup work inside the developer flow. Standard searches open in the browser, -d switches to DuckDuckGo, -n opens Chrome incognito, and -a sends the query to Perplexity for an inline terminal answer.

Install via clone

git clone https://github.com/alexprofmutua/go_search.git
chmod +x go.sh
sudo mv go.sh /usr/local/bin/go
