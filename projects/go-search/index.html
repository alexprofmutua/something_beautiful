go_search

A search starts in the terminal.

Problem and motivation

go_search provides a short shell entry point for browser searches. It keeps search flags in the terminal and supports an optional API answer without opening a search page.

Main functionality

  • Open a Google search from the terminal.
  • Select DuckDuckGo with -d, or Chrome incognito with -n.
  • Request a Perplexity answer with -a.
  • URL-encode query text before sending it to a browser or API.

Technology stack

Bash
Flag parsing, command routing, and browser launch.
Python
URL encoding and the Perplexity HTTP request.
Perplexity API
Optional answers returned to the terminal.

Technical implementation

The Bash command parses search flags, uses Python to URL-encode a query, and opens the selected browser search. The -d flag selects DuckDuckGo, -n uses Chrome incognito, and -a requests a Perplexity answer.

The script uses getopts for flags and Python's urllib.parse.quote for query encoding. Browser mode builds a search URL; AI mode uses urllib.request to send a JSON request and print the returned answer.

Inside the source

go
Bash command, search routing, and optional AI modes.

Platform and API constraints

The inspected browser-launch path uses macOS open commands and Chrome for incognito mode. That is a platform dependency, rather than a claim of support for every operating system.

AI mode requires PERPLEXITY_API_KEY in the environment. Standard Google and DuckDuckGo searches do not use that API key.

Run locally

git clone https://github.com/alexprofmutua/go_search.git
cd go_search
bash go -d "chess openings"

The inspected script uses macOS browser-opening commands. Its AI mode needs Perplexity credentials; the examples here are browser searches.
