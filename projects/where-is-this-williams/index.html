Web app / campus game

Where Is This Williams

How well do you know campus?

JavaScript · HTML / CSS · Node.js · Supabase

View Where Is This Williams on GitHub ↗ (opens in a new tab)

Problem and motivation

Where Is This Williams turns campus photos into a shared guessing game. It connects weekly location questions with individual voting histories and a public score table.

Main functionality

  • Enter a Williams email and Instagram username to participate.
  • Guess campus locations from weekly photos and submit a final score.
  • Compare scores on the leaderboard and podium.
  • Review previous guesses and earn participation achievements.

Technology stack

JavaScript / HTML / CSS
The photo questions, browser interface, and page styling.
Node.js
The local server, submission routes, and validation.
Supabase
Player records, votes, scores, and account services.

Technical implementation

Players enter their Williams email and Instagram username, identify campus locations, and submit a final score. The app stores voting history and updates a public leaderboard. Its Supabase connection and one-submission flow keep the game state consistent.

The browser pages and Node.js routes are separate from the Supabase storage layer. server.js checks email verification and existing votes before accepting submissions. Its Supabase helpers keep service-role credentials on the server.

Submission and persistence constraints

Repeated submissions need checks beyond the browser interface. The server rejects a duplicate vote for the same player and photo with a conflict response.

The README documents Supabase environment configuration for keeping player records and scores available after a redeploy. The local application opens at http://localhost:3000/login.html.

Run locally

git clone https://github.com/alexprofmutua/where_is_this_williams.git
cd where_is_this_williams
npm install
npm start

The server needs the Supabase configuration described in the repository README.
