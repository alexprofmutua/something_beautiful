macOS app / desktop utility

MultiDock

Give each group of apps its own place on your desktop.

Swift 6 · AppKit · SwiftUI · macOS

View MultiDock on GitHub ↗ (opens in a new tab)

Problem and motivation

A single application tray puts every app in one place. MultiDock lets users keep separate groups around the desktop, with independent placement and behavior for each dock.

Main functionality

  • Create multiple horizontal or vertical docks with their own apps, position, and appearance.
  • Add apps by drag and drop, reorder them, or move and copy entries between docks.
  • Use stacks, folder shortcuts, running indicators, magnification, and app-name labels.
  • Enable auto-hide with small reveal tabs, and customize tab colors per dock.
  • Save layouts locally and manage docks from the menu-bar settings.

Technology stack

Swift 6
Application logic, dock configuration, and local persistence.
AppKit
Floating panels, native application launching, and desktop window behavior.
SwiftUI
Dock contents and settings hosted within the native application.

Technical implementation

Each dock uses a nonactivating AppKit NSPanel. Its icons accept clicks without taking keyboard focus from the application in use. SwiftUI supplies the dock contents, while AppKit manages the panels and application lifecycle.

Versioned configuration preserves dock identities, app order, appearance, and positions. Writes are serialized, debounced, and atomic. Recoverable configuration changes are backed up before saving; normal quit flushes pending edits.

The app uses documented Apple APIs and has no third-party packages, account system, telemetry, or backend.

Auto-hide and dock placement

Permissions and current limits

Ordinary docks work without Accessibility or Screen Recording permission. Optional window previews require Screen Recording; advanced window controls require Accessibility.

The repository describes version 0.10.0 as a personal-use release candidate. Local builds are ad-hoc signed, not notarized. External-display transitions and permission-granted window controls still need manual verification.

Build locally

Requires an Apple Silicon Mac, macOS 14 or later, and a Swift 6 toolchain through Xcode or Command Line Tools.

git clone https://github.com/alexprofmutua/MultiDock.git
cd MultiDock
./Scripts/build-release.sh
./Scripts/install-local.sh

The build produces dist/MultiDock-arm64.zip; the installer places the app in ~/Applications. Open MultiDock.xcodeproj for Xcode development. See the repository build instructions ↗ before installing.
