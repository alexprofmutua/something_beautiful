CLI / developer tool

colorBash

Color exact file and folder names in ls.

Bash · Shell integration · Homebrew

View colorBash on GitHub ↗ (opens in a new tab)

Problem and motivation

Native ls colors are usually tied to file types. colorBash adds rules for exact names, so one familiar folder can keep a distinct color in a busy directory listing.

Main functionality

  • Save an exact-name rule with cb <name> <color>.
  • Assign directory-scoped random colors to visible entries with cb random.
  • Wrap supported interactive ls forms while preserving the native command for other modes.
  • List, remove, or clear saved color rules.

Technical implementation

colorBash stores exact-name color rules and applies them to interactive ls output. It also supports directory-scoped random rules. The shell integration is the interesting part: it changes the everyday listing workflow while keeping the system command available.

Rules are stored in ~/.config/colorbash/rules.tsv. Random rules are scoped to the current directory. The wrapper handles a limited set of interactive ls forms and passes unsupported modes through to the system command.

Shell compatibility

The documented scope includes ls, ls -a, ls -A, and ls -1. Keeping other forms on native ls avoids trying to reproduce every system listing option.

CROSS-PLATFORM.md describes BSD/GNU ls handling. macOS and Linux use a Bash-compatible shell; Windows needs Git Bash or WSL rather than native PowerShell or cmd.

cd colorBash
./install.sh --configure-shell
