colorBash

Color any exact file or folder name in ls — not just by type.

Pure Bash · macOS · shell hooks · zero runtime dependencies

macOS only colors directories one way. colorBash wraps interactive ls so you can pin colors to exact names with cb, randomize a whole directory, and keep the terminal feeling completely native.

Install via Homebrew

brew install amm22-lab/colorbash/colorbash
echo 'eval "$(colorbash init)"' >> ~/.zshrc
